# Captures d'écran

Captures prises le 6 novembre 2026 sur la version actuelle de l'application. Les
tweets affichés sont de **vrais tweets de @Sardoche du 5 novembre 2026**, collectés
via la source `profile` puis analysés par OpenCode (DeepSeek V4.1 Flash). Aucune
capture ne montre de données mock.

| Fichier | Contenu |
| --- | --- |
| `home.png` | Accueil desktop : hero, BullshitMètre, répartition des verdicts et indicateurs |
| `une.png` | Accueil desktop : tweet à la une avec embed X, citation G2 Esports et compteurs |
| `liste.png` | Accueil desktop : liste des dernières analyses avec médias, citations et scores |
| `detail.png` | Page détail desktop du tweet Perkz/G2 : embed à gauche, score et verdict à droite, analyse et fact-checks en pleine largeur |
| `detail-photo.png` | Page détail desktop d'un tweet avec photo : embed, score 3/100, analyse et fact-checks |
| `mobile.png` | Accueil mobile : hero, BullshitMètre et filtres, sans débordement horizontal |
| `detail-mobile.png` | Page détail mobile : embed, panneau de score et début de l'analyse |

Les captures `detail.png` et `detail-photo.png` correspondent à des analyses réelles
enregistrées en base. Les scores peuvent évoluer après une réanalyse : la capture est
un instantané, pas une valeur garantie.
