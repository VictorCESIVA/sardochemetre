# Archives documentaires

Les fichiers de ce dossier sont conservés pour l'historique du projet. Ils ont été
rédigés à différentes étapes du développement et **ne décrivent plus nécessairement
l'état actuel du dépôt**.

Ils peuvent notamment contenir :

- des affirmations de statut (« tout fonctionne », « 100 % terminé ») qui n'ont pas
  été revérifiées ;
- des chemins, commandes ou noms de fichiers qui n'existent plus ;
- des choix techniques abandonnés (PostgreSQL obligatoire, ancien modèle Puter,
  ancienne arborescence) ;
- des rapports de test antérieurs aux versions actuelles.

La documentation de référence se trouve dans :

- [`../../README.md`](../../README.md) — présentation et démarrage rapide ;
- [`../SETUP.md`](../SETUP.md) — installation et configuration ;
- [`../ARCHITECTURE.md`](../ARCHITECTURE.md) — fonctionnement interne ;
- [`../AI_MODE.md`](../AI_MODE.md) — IA et analyses OpenCode ;
- [`../DEPLOYMENT.md`](../DEPLOYMENT.md) — déploiement.

Le dossier `../../archive/sardochemetre-scaffold/` contient un ancien squelette de
projet sans code applicatif, déplacé hors de la racine pour éviter toute confusion.
