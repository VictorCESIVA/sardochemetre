🚀 QUICK START (After installing Node.js & PostgreSQL):

# 1. Database Setup
sudo -u postgres psql -c "CREATE DATABASE sardochemetre;"
cd backend && cp .env.example .env
# Edit .env with database credentials

# 2. Install & Setup Backend
npm install
npm run migrate
npm run init-data

# 3. Test Backend
npm run test-imports  # Verify modules load
npm start             # Start server on :3001

# 4. Install & Run Frontend (in new terminal)
cd frontend
npm install
npm run dev           # Start dev server on :5173

# 5. Test in Browser
Open: http://localhost:5173
